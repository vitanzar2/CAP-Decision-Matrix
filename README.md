# CAP-Decision-Matrix

A tiny **Civil Air Patrol Decision Maker 9,000** web app.

## Run locally

1. From this folder, run:
   ```bash
   python3 -m http.server 8000
   ```
2. Open <http://localhost:8000> in your browser.
3. Type any question and click **Consult the 9,000** to get a random outlandish response.
